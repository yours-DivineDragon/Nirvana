# Security policy

Use Nirvana only on systems you own or are explicitly authorized to test.

Do not open a public issue containing an undisclosed vulnerability, exploit payload, private target code, credential, or live-system detail. Contact the repository owner through a private channel and include the affected revision, minimized reproducer, impact, assumptions, and suggested mitigation.

Nirvana must never automatically publish target findings or transact against a live chain. Coordinated disclosure remains a human decision.
